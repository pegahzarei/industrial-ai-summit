第2回

ソウル

韓国のエネルギー、精製、化学、製造業界のリーダーが集結。KAIST と INEEJI が登壇し、アカデミックな色合いの回となりました。

日程
2026年7月20日（月）
時間
12:50 KST から午後のプログラム、その後ネットワーキングディナー。
会場
JW Marriott Hotel Seoul
所在地
ソウル、江南

当日

東京開催の4日後、サミットは JW Marriott Hotel Seoul で再び開かれ、韓国のエネルギー、精製、化学、製造業界のリーダーが集いました。市場は違っても、基準は同じです。実際に動かして見せること。

この回はアカデミックな色合いが強くなりました。Jaesik Choi 教授は、プラントが信頼するのは単に予測するAIではなく、問いただせるAIだけだと論じました。Young Jae Jang 教授は、パイロットプロジェクトと本番環境で稼働するシステムとの間にあるギャップを取り上げました。

講演

  1. 01

    オープニング基調講演

    産業AIを本番環境で機能させるために何が必要かを語り、午後のプログラムの幕を開けました。

    Moe TanabianIntuigenceAI 創業者兼CEO
  2. 02

    Microsoft Fabric によるエージェント型オペレーション

    東京に続き Microsoft Fabric をテーマに、プラントデータ上で動くエージェントについて語りました。

    Christoph BerlinMicrosoft エンジニアリング担当VP
  3. 03

    プラントが信頼するのは、問いただせるAI

    INEEJI の実運用事例をもとに、プラントが信頼するのは単に予測するAIではなく、問いかけることのできるAIだけだと論じました。

    Jaesik ChoiINEEJI CEO、KAIST 説明可能AIセンター長
  4. 04

    パイロットプロジェクトから、稼働し続けるシステムへ

    産業AIのパイロットと、日々稼働するシステムとの間のギャップを取り上げました。

    Young Jae JangKAIST 産業システム工学科 教授
